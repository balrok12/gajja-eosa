개인정보처리방침 (Privacy Policy)

가짜 어사 업로더 · 시행일 2026-10-21

1. 이 도구가 하는 일

가짜 어사 업로더는 유튜브 채널 《가짜 어사》 운영자 한 사람만 쓰는 개인용 프로그램입니다. 운영자 본인의 영상을 운영자 본인의 유튜브 채널에 올리기 위해 YouTube Data API(YouTube API 서비스)를 사용합니다.

2. 사용하는 정보

운영자가 구글 로그인으로 허용한 권한(유튜브 계정 관리)만 사용합니다. 쓰는 기능은 영상 올리기, 올린 영상의 상태 확인, 운영자 채널의 재생목록 확인과 재생목록에 영상 넣기뿐입니다.

3. 저장과 공유

로그인 정보(OAuth 토큰)는 운영자 본인의 컴퓨터에만 저장되며, 어떤 서버로도 보내지 않습니다. 다른 사용자의 개인정보를 모으거나 저장하거나 제3자에게 제공하지 않습니다. 광고나 분석 도구도 쓰지 않습니다.

4. 권한 해제

언제든지 Google 계정의 서드 파티 액세스 설정에서 이 도구의 권한을 없앨 수 있습니다.

5. YouTube와 Google 정책

이 도구는 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

6. 문의

유튜브 채널 《가짜 어사》를 통해 문의할 수 있습니다.

Summary (English)

Gajja Eosa Uploader is a private tool used only by the owner of the YouTube channel "가짜 어사". It uses YouTube API Services to upload the owner's own videos to the owner's own channel (videos.insert, videos.list, playlists.list, playlistItems.insert). The OAuth token is stored only on the owner's computer and is never sent to any server. The tool does not collect, store or share any other user's data and uses no advertising or analytics. Access can be revoked at any time at Google account permissions. By using YouTube API Services you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.
