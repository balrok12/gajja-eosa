다른 사람의 계정이나 정보에는 접근하지 않으며, 외부에 공개된 서비스가 아닙니다.

This is a private desktop tool used only by the owner of the YouTube channel "가짜 어사 (Gajja Eosa)". It uploads the owner's own original videos to the owner's own channel and sets the title, description, tags, playlist and scheduled publish time through the YouTube Data API. It has a single user and no public interface.
